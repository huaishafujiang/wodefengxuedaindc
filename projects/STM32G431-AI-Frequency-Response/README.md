# STM32G431 频响测量与 AI 诊断系统

本项目已整理进 `wodefengxuedaindc` 仓库，作为一个独立的 STM32G431 测量与分析项目保留。

项目以 STM32G431 为核心，完成扫频激励、ADC/DMA 采样、串口数据传输和频率响应计算；上位机负责数据导入、曲线绘制、传递函数拟合、滤波器分析、控制补偿以及元件偏差诊断，并支持将测量结果导出为报告。

目录说明：

- `01_上位机_软件与应用`：Python 上位机、分析算法、GUI 和测试脚本
- `02_下位机_STM32G431固件`：STM32G431 固件工程与外设配置
- `测量数据`：频响测量样例数据
- `视频素材`：项目演示素材

硬件链路为信号激励、被测电路、ADC 采样和串口回传；软件链路为采集、校准、拟合、诊断和报告输出。项目适合用于嵌入式测量、控制系统辨识和 AI 辅助故障分析的综合演示。

来源：本目录依据本地 G431 项目仓库 `main` 分支快照整理。GitHub 源链接当前为空仓库，因此本次导入以本地已验证项目文件为准。
